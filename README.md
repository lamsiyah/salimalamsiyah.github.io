# Salima Lamsiyah — Academic website

A lightweight, responsive static website for GitHub Pages. No build step is required.

## Pages
- `index.html`: complete single-page academic profile, with a persistent section menu, research, academic history, teaching, service, all publications, and contact.
- `publications.html`: searchable full bibliography with publication statuses.
- `cv.html`: public professional CV, with print/save-as-PDF styling.

## Update
Edit the HTML pages directly. `publications.json` is an accompanying structured bibliography snapshot; keep it in sync with the bibliography in `index.html` and `publications.html`. Styling is in `styles.css`; mobile navigation and publication filtering are in `site.js`.

The supplied portrait is optimized for web display. Public documents are in `assets/`. The web CV intentionally uses professional contact information, omitting the private phone number, home location, and referees' contact details from the supplied original CV.

## GitHub Pages
Publish the `main` branch, root folder, in repository Settings → Pages. The intended URL is https://lamsiyah.github.io/salimalamsiyah.github.io/.
